# 术中低血压预测医疗AI系统 (Intraoperative Hypotension Prediction)

> 上海电机学院电子信息专业研一科研项目：基于TCN-Attention混合模型，利用术中生命体征时序数据实现低血压短时预警。

## 项目简介
本项目针对手术过程中低血压（Intraoperative Hypotension）风险，构建了一套端到端的人工智能预测系统。
通过挖掘心率、血氧、血压等生命体征时序信号中的潜在规律，实现对未来5-10分钟低血压风险的精准预警。

## 核心功能
- 🧹 **数据预处理**：自动处理缺失值、异常值截断、线性插值与前向填充
- 📈 **特征工程**：提取均值、中位数、斜率、变化率等时序统计特征
- 🤖 **多模型对比**：集成逻辑回归、随机森林、XGBoost 三种经典模型
- 🔬 **LOSO 交叉验证**：针对小样本医疗数据，采用留一法交叉验证评估模型性能
- 🩺 **事件捕获率**：自定义评估指标，衡量对真实低血压事件的预警能力

## 技术栈
- **语言**：Python 3.11+
- **核心库**：Pandas, Scikit-learn, XGBoost, NumPy
- **数据处理**：时序数据清洗、特征工程、异常值处理
